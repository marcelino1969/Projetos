# 📋 Sistema de Gestão de Rotina Diária

> **Status do Projeto:** 🚀 Concluído & Funcional

Este é um script interativo em Python projetado para ajudar no planejamento diário, permitindo o cadastro de tarefas e gerando um feedback personalizado sobre a intensidade da rotina do usuário com base no volume de atividades.

## ⚙️ Como Funciona (Lógica de Cálculo)

O programa avalia a quantidade de tarefas cadastradas pelo usuário e classifica o dia utilizando a seguinte lógica condicional:

* **0 tarefas:** Retorna `Nenhuma tarefa cadastrada.`
* **1 a 3 tarefas:** 🟢 **Rotina Leve** -> `"{Nome} de {Cidade}: rotina leve hoje!"`
* **Mais de 3 tarefas:** 🔴 **Rotina Cheia** -> `"{Nome} de {Cidade}: rotina cheia! Organize prioridades."`

## 🚀 Como Executar o Programa

### Pré-requisitos
Você precisa ter o **Python 3.x** instalado em sua máquina.

### Passo a Passo

1. **Clone o repositório** (ou baixe o arquivo `.py`):
   ```bash
   git clone https://github.com
   ```

2. **Navegue até a pasta do projeto**:
   ```bash
   cd nome-da-pasta
   ```

3. **Execute o script**:
   ```bash
   python nome_do_arquivo.py
   ```

4. **Interaja com o terminal**: Insira seu nome, cidade e a quantidade de tarefas para ver o resultado!
